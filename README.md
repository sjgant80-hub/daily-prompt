# The Daily Prompt — AI the right way

**▶ Live: https://sjgant80-hub.github.io/daily-prompt/**

One genuinely useful AI **system prompt**, free, every day — the kind "AI course" sellers lock behind
a paywall and an email list. Copy-paste, no sign-up, no upsell. A new one rotates in automatically each
day (deterministic by UTC date, no server); the whole library is open.

Each prompt ships with **why it works** — tied to a principle from the free course
[falllearn](https://sjgant80-hub.github.io/falllearn/), because the skill is the point, not the paywall.
No fake metrics, no estate jargon; the value is the prompt itself.

- `prompts.json` — the library (16+ real system prompts).
- `daily.mjs` — the pure, **witness-clean** kernel that picks today's prompt deterministically.
- `index.html` — the page, skinned by [fallskin](https://sjgant80-hub.github.io/fallskin/), with copy buttons and the full archive.
